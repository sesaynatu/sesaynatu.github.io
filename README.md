# Project 5.8 – Deployment and Local Hosting

## Project Overview
This project is a responsive website built using HTML5 and CSS3. The purpose of this project is to document the website, deploy it using GitHub Pages, and launch it locally using XAMPP.

## Live Website (GitHub Pages)
Live URL: https://sesaynatu.github.io/

## Repository Link
Repository URL: https://github.com/sesaynatu/sesaynatu.github.io

## Local Hosting (XAMPP)
### Steps Used
1. Installed XAMPP.
2. Started Apache in the XAMPP Control Panel.
3. Copied the project folder into the htdocs directory.
4. Opened the website using http://localhost/.
